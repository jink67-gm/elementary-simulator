# 에셋 제작 계획 (STEP 1~5 보고)

작성일: 2026-11-12 · 상태: **승인 대기** (STEP 6부터는 승인 후 진행)

## STEP 1. 기존 프로젝트 분석

- 1장(등교~급식실 전환)이 Three.js로 동작 중. 브라우저 자동 플레이 테스트(`scripts/e2e.mjs`) 15단계 통과.
- 지금 그래픽은 **전부 기본 도형**(블록 인물 `src/world/Character.ts`, 상자 교실 `src/world/SchoolMap.ts`). 이번 요청의 "네모난 캐릭터 금지"에 정확히 해당하므로 교체 대상.
- 교체가 쉬운 구조: 인물은 `Character` 한 곳(포즈 `stand/walk/run/sit/raise/cheer`, 머리 돌리기, 손 위치)만 GLB+애니메이션 버전으로 바꾸면 플레이어·NPC 15명이 모두 바뀜. 게임 로직(상호작용·저장·이야기)은 그대로.
- 게임 로직이 기대하는 캐릭터 크기: 학생 키 약 1.35m, 교사 약 1.73m, 반지름 0.3m 충돌.

### 가장 안정적인 조합 (제안)

```
Higgsfield 이미지 모델 ──(캐릭터 설정화: 앞/옆, A포즈)──▶ Higgsfield image_to_3d (+자동 리깅, +걷기·달리기·대기 프리셋)
        ──GLB──▶ 헤드리스 Blender(bpy): 크기 맞춤 · 뼈 이름 통일 · 폴리곤/텍스처 줄이기 · 수업 동작(앉기·손들기 등) 키프레임 추가
        ──GLB──▶ gltf-transform 최적화 ──▶ public/models/ ──▶ Three.js (AnimationMixer로 하나의 리그에서 동작 공유)
```

- 원본은 `assets/source/`(생성 결과 그대로), 게임용은 `public/models/`(최적화본)로 나눠 보관.
- 모든 파일은 저장소 안에 들어가므로 **구독을 끝내도 게임은 로컬 파일만으로 실행**됨.

### Higgsfield를 쓰려면 사용자가 할 일 (둘 중 하나)

1. **권장**: claude.ai → 커넥터(https://claude.ai/customize/connectors)에서 **Higgsfield 커넥터를 연결**하고 새 세션을 시작. 로그인은 그 화면에서 직접.
2. 또는 이 환경의 네트워크 허용 목록에 Higgsfield 주소를 추가하고, 세션 안에서 CLI 로그인 진행 (로그인 화면은 사용자가 직접 승인).

결과 GLB를 내려받는 저장소 주소(CDN)는 첫 생성 결과를 보고 정확한 호스트만 추가 요청함.

## STEP 5. 비용과 크레딧

- **작업당 크레딧 소모량과 무료 체험 잔량은 로그인 전에는 알 수 없음.** 연결되면 먼저 `higgsfield account`와 `higgsfield model get`으로 확인해 아래 표에 실제 숫자를 채워 다시 승인을 받음.
- 예상 **작업 횟수**(재시도 포함 범위):

| 단계 | 이미지 생성 | 3D 생성(리깅 포함) | 리깅·애니메이션 추가 | 합계 |
|---|---:|---:|---:|---:|
| 1차 관문: 남학생 1명 | 2~4 | 1~2 | 1~3 | **4~9** |
| 1차 나머지 캐릭터 9명 | 18~36 | 9~18 | 0~9 | 27~63 |
| 3차 돈가스·기계 | 5~10 | 6~12 | 0 | 11~22 |
| 4차 로봇·마스코트 등 | 4~8 | 4~8 | 0~2 | 8~18 |
| **전체** | | | | **약 50~110회** |

- 2차(교실·복도)는 무료(CC0+코드)라 크레딧 0.
- Higgsfield 외 다른 유료 서비스 가입·결제는 하지 않음.

## 라이선스 확인 결과 (요약, 자세한 내용은 `ASSET_LICENSES.md`)

- Higgsfield 공식 도움말: 생성물의 소유권을 회사가 주장하지 않고, 이용약관이 상업적 이용을 막지 않는다고 안내. 단 **약관이 2026-08-27에 개정**되었고 무료 체험 결과물에 제한이 있다는 제3자 글도 있어, 연결 후 실제 약관 문구와 체험 조건을 확인한 뒤 배포 여부를 확정함.
- 생성물로 AI를 학습시키는 것은 금지(우리 용도와 무관).
- 프롬프트에 실제 인물·학생 사진·유명 캐릭터를 넣지 않음. 얼굴은 전부 가상 인물로 설명만 사용.
