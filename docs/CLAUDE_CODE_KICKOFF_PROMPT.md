# Claude Code에 전달할 첫 요청문

다음 프로젝트를 함께 개발하자. 지금부터는 전체 게임을 한꺼번에 구현하지 말고 **단계적으로 실제 플레이 가능한 완성도를 확인하면서** 개발해 줘.

게임 제목: 《초등학생 시뮬레이터: 오늘도 무사히 하교하기》.
대상: 한국 초등학생. 3인칭 3D 브라우저 게임.
목표: 실제 초등학교 오전(등교/국어/쉬는 시간/수학/모둠 활동/미술)을 현실적으로 체험하다가, AI 학교생활 도우미가 소원을 문자 그대로 이뤄 주면서 급식실 거대 돈가스→청소 로봇→거대 피구공→무한 복도→최종 AI 사건으로 이어지는 코미디 시뮬레이터.

**반드시 먼저 읽을 파일**
- GAME_DESIGN.md
- CLAUDE.md
- MCP_SETUP.md
- ASSET_MANIFEST.csv
- .claude/skills/ 안의 SKILL.md 3개

**우선 작업**
1. 이 기획의 핵심 루프와 구현 위험을 1페이지로 요약.
2. 현재 폴더/기존 코드를 확인. 없으면 Vite + TypeScript + Three.js 기본 프로젝트를 생성.
3. 3인칭 이동, 마우스 카메라, 충돌, 상호작용(E 조사/집기, F 사용/놓기), 한국어 HUD, 최소 NPC 대화 시스템 구현.
4. 플레이 가능한 학교 교실·복도 프로토타입 제작(임시 모델 사용 가능).
5. 급식표 확인/교과서 86쪽 펴기/친구 대화/태블릿 3% 배터리 등 공감형 활동 4개 구현.
6. 브라우저에서 직접 실행/테스트 후 콘솔 에러·조작 문제를 수정.
7. 완료된 기능, 아직 구현되지 않은 기능, 다음 Phase 계획을 구분해 보고.

**반드시 지킬 개발 원칙**
- 주인공의 행동이 선택이 된다. A/B/C 메뉴만 클릭하는 스토리로 만들지 말 것.
- 이벤트를 슬라이드쇼나 정적인 연출로 대체하지 말 것.
- 점심 전 오전 생활이 단순 튜토리얼이 아니라 재미있는 게임이어야 함.
- 모든 사건이 피하기 게임이 되면 안 됨.
- 한국어 대사는 자연스럽고 1~2줄, 친구의 사소한 실수에 웃되 조롱은 금지.
- 우선 독립 싱글 플레이. Firebase/멀티플레이/실명 수집 도입 금지.
- 저사양 학교 노트북을 고려, 저장/재시작 가능.
- 에셋은 공식 링크로 실제 다운로드 가능한지 확인 후 사용. 라이선스별 기록. 의심스러운 에셋은 직접 기본 도형으로 제작.
- MCP나 플러그인은 필요 시 설치 이유를 설명하고 승인받은 뒤 사용. 외부 유료 API/서비스 가입을 임의로 추진하지 말 것.
- 기능은 브라우저에서 검증하지 않았다면 ‘완료’라고 표현하지 말 것.

**이번 응답에서 가장 먼저** Phase 0~1의 작업 계획과 파일 구조를 설명한 다음, 그 단계까지만 실제 구현해 줘.
