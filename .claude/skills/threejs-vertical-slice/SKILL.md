# Three.js Vertical Slice

- Vite+TypeScript+Three.js로 구현하고, HUD는 HTML/CSS가 기본.
- 매 기능은 이동→대상 접근→E 상호작용→반응→퀘스트 상태 업데이트→저장까지 연결.
- 카메라·충돌·상호작용 레이캐스트·인벤토리·상태 머신을 분리한다.
- 이벤트 단위로 고유 ID, 전/후 조건, 실패 복구와 스킵 시 처리를 정의한다.
- 퀘스트 완료는 버튼 클릭이 아닌 실제 월드/데이터 조건으로 판정.
- 모델은 GLB 우선. 오브젝트가 없을 때 기본 도형 대체하고 원인 안내.
- 공개 배포 전에 Vite base 경로, 404 에셋, 콘솔 오류, 새로고침 복구 검증.
- 새 장면을 늘리기보다 ‘동작하는 교실+NPC+활동’ 하나의 완성도를 먼저 올린다.
