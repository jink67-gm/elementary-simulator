# 초등학생 시뮬레이터: 오늘도 무사히 하교하기

평범한 월요일 오전을 보내다가, AI 학교생활 도우미가 소원을 **문자 그대로** 이뤄 주면서 학교가 엉망이 되는 3인칭 3D 브라우저 게임.
지금 버전은 **오전 수업(1장) → 사건 1 거대 돈가스 → 사건 2 청소 로봇 → 사건 3 거대 피구공 → 사건 4 끝나지 않는 쉬는 시간 → 최종 사건 AI 학교생활 도우미 → 엔딩 3종**까지, 처음부터 끝까지 플레이할 수 있어요.

- 기획서: [`GAME_DESIGN.md`](GAME_DESIGN.md) · 개발 규칙: [`CLAUDE.md`](CLAUDE.md) · 에셋 출처: [`assets/SOURCES.md`](assets/SOURCES.md)
- 1인 플레이, 브라우저에만 저장. 로그인·방 만들기·실명 입력 없음 → 학교 컴퓨터 8대에서 각자 바로 실행.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173/elementary-simulator/
```

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사 + `dist/`에 배포용 파일 |
| `npm test` | 로직 단위 테스트 (Vitest) |
| `npm run e2e` | 빌드된 게임을 브라우저로 처음부터 끝까지 자동 플레이 (Playwright 필요, 스크린샷은 `test-results/`) |
| `npm run e2e:touch` | 태블릿 손가락 조작 자동 테스트 + 태블릿·크롬북·웨일북·노트북 화면 크기별 겹침 검사 (`test-results/devices/`) |

### GitHub Pages 배포
1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꾼다.
2. `main` 브랜치에 올리면 `.github/workflows/deploy.yml`이 테스트·빌드 후 배포한다.
3. 주소: `https://<계정>.github.io/elementary-simulator/` (저장소 이름을 바꾸면 `vite.config.ts`의 `base`도 바꿔야 함)

## 학교 구조 (우리초등학교, 2층 건물)

학교 이름은 `src/data/school.ts`의 `SCHOOL_NAME` 하나만 바꾸면 정문 간판·현관 안내도·강당 현수막·도서관 문구가 모두 바뀝니다.

| 층 | 들어갈 수 있는 곳 | 닫힌 문 (이름표만) |
|---|---|---|
| 2층 | 6-1(우리 반), 복도, 급식실, 강당, 방송실(최종 사건) | 4-1, 5-1, 도서관, 화장실 |
| 1층 | 현관(신발장·학교 안내도), 복도 | 1-1 · 2-1 · 3-1, 교무실, 행정실, 보건실 |

등교는 1층 현관 앞에서 시작해 계단으로 2층에 올라가요. 다른 층에 있는 목표는 노란 화살표가 계단을 먼저 가리켜요.

## 조작

| 키 | 동작 |
|---|---|
| WASD / Shift | 이동 / 달리기 |
| 마우스 (화면 클릭) · 방향키 · 휠 | 둘러보기 · 카메라 거리 |
| **E** | 조사·줍기·대화 |
| **F** | 들고 있는 물건 사용·놓기 (빈손일 때 손 들기 등) |
| Space | 점프 / 종이비행기를 들고 꾹 눌렀다 떼면 던지기 |
| 1~4 / Tab | 소지품 고르기 / 설명 |
| E · Q | 대사 넘기기(마지막 줄에서 닫기) · 모두 넘기기 |
| Esc | 메뉴 (설정·자리로 돌아가기·물건 다시 챙기기·저장 파일 내보내기) |

### 기기별 (태블릿 · 웨일북 · 크롬북 · 노트북)

조작 방식은 **자동**으로 바뀝니다: 화면을 손가락으로 만지면 터치 버튼이 나오고, 키보드를 누르거나 마우스를 움직이면 다시 키보드·마우스 조작이 됩니다. (설정 → 조작 방식에서 고정 가능)

| 터치 | 동작 |
|---|---|
| 왼쪽 화면 누르고 끌기 | 이동 조이스틱 (살짝 = 걷기, 끝까지 = 달리기) |
| 오른쪽 화면 끌기 / 두 손가락 벌리기 | 둘러보기 / 카메라 거리 |
| **E** 버튼 | 지금 할 수 있는 행동 이름이 버튼에 바로 뜸 (줍기·대화·다음 대사) |
| **F** 버튼 | 사용·내려놓기 (할 수 있을 때만 보임) |
| ␣ 버튼 | 점프 / 종이비행기 꾹 눌렀다 떼기 / 원격 조종 집게 |
| 소지품 칸 톡 · 대화창 톡 · 메뉴 버튼 | 고르기(한 번 더: 설명) · 대사 넘기기 · 메뉴 |

- **태블릿(iPad·갤럭시 탭)**: 가로 화면용. 세로로 들면 돌려 달라는 안내가 나와요. 메뉴의 **전체 화면으로 보기**를 누르면 주소창 없이 넓게 보여요.
- **웨일북·크롬북**: 처음 켜면 그래픽이 「낮음」으로 시작하고, 버벅이면 해상도를 저절로 조금씩 낮춰요(설정에서 끌 수 있음). 터치패드 두 손가락 스크롤 = 카메라 거리, 화면을 클릭하면 터치패드로 둘러보기, 방향키로도 둘러볼 수 있어요. 터치 화면이 있는 기기는 손가락과 키보드를 섞어 써도 돼요.
- **작은 화면(1280×720·1024×600)**: 글자·카드·소지품 칸이 화면 높이에 맞춰 작아져요.

## 1장에서 할 수 있는 것

선택지 버튼이 아니라 **실제로 물건을 만지고 친구와 말하는 행동**이 기록(플래그)으로 남고, 1장 끝 화면과 다음 사건에 이어집니다.

| 구간 | 실제 행동 | 남는 기록 |
|---|---|---|
| 알람 | E 일어나기 / Space 5분만 더 | `overslept` (선생님 대사 변화) |
| 등교 | 가방 들고 책상에 F, 17번 사물함에서 국어책, 급식표 3번 보기, 복도에서 준호 필통 찾아 돌려주기 | `bagOnDesk` `lunchExpert` `helpedFriend` |
| 1교시 국어 | 교과서 넘겨 86쪽 찾기(한 장/뭉텅이), 서아에게 쪽수 알려 주기, 단서 문장 찾기, 짝과 의견 나누기, F로 손 들고 발표 (안 해도 자연스럽게 진행) | `helpedPageFriend` `foundClue` `consultedPartner` `spokeInClass` |
| 쉬는 시간 60초 | 준호 종이비행기 받아 복도에서 날리기(거리 기록), 민재와 가위바위보, 공차기, "쉬는 시간 100분" 복선 | `planeBest` `rpsGames` |
| 2교시 수학 | 충전함에서 태블릿 → 책상에 놓고 켜기, 서아 3% 배터리: 선생님 서랍 충전기 찾아 주기 또는 같이 보기, 퀴즈 3문제(4~6학년 설정), AI 소원 설문 | `helpedDevice` `quizScore` `playerWish` |
| 3교시 모둠 | 역할 카드 집기 → 발표(문장 카드 배열) / 제작(포스터 스티커 끌어 놓기) / 자료(게시판·전자칠판·학급 문고 조사, AI 설명서 단서) / 정리(재료 6개를 바구니에 분류) | `groupRole` `schoolPosterTheme` `foundAIManual` |
| 4교시 미술 | 색종이 → 종이비행기 접기(화살표) 또는 도화지 → 하린에게 풀 빌려 미니 포스터, 게시판 전시, 풀 돌려주기, 친구들 초고속 정리, 종이 조각 분리수거 | `artPlane/artPoster` `exhibited` `returnedGlue` |
| 점심 | 급식실 앞 AI 방송 → 문이 열리고 거대 돈가스 등장 | `chapter1Done` |

## 오후 사건 (각각 세 가지 해결 방법, 선택지 버튼 없음)

| 사건 | 해결 방법 (실제 행동) | 남는 기록 · 앞 사건과의 연결 |
|---|---|---|
| 1 거대 돈가스 (급식실) | ① 창고의 안전 절단기를 식탁에 걸고 패널에서 절단선 + 압력 게이지로 자르기 → 식판 깔고 친구 6명에게 배식 ② 창고 구석 크기 조절기: 스티커 보고 전선 꽂기 → ÷2·÷5·−100으로 정확히 100% ③ 방송실 마이크 → 조리사 허락 → 복도에 테이블 3개 → 친구 3명 초대 → 안내 방송 순서 맞추기 | `cafeteriaSolution` `sharedFairly` `fixedMachine` `festivalHeld` `cutletCrumbs` |
| 2 청소 로봇 (교실) | ① 제어 패드로 로봇 직접 조종(WASD·Space 집게) → 수거함에서 집어 분실물 보관함 칸에 분류 ② 청소 금지 고깔 3개 + 저장 → 로봇이 스스로 돌려놓음 ③ 서아·준호·하린에게 비상정지 코드 한 자리씩 → 로봇 정지 → 주인에게 직접 돌려주기 | `results.robot` `robotReprogrammed` `itemsRestored` `messLevel` · 공평 배식이면 친구가 도움, 축제를 열었으면 포스터도 수거됨 |
| 3 거대 피구공 (체육관) | ① 받침대·경사판·패드 조립 → 각도·힘 맞춰 뜀틀 피해 공 창고로 (3번 실패하면 예상 경로 표시) ② 크기 조절 리모컨으로 100% → 공 수레에 (사건 1에서 기계를 고쳤을 때만) ③ 안전한 규칙 카드 3장 → 친구들과 몸으로 밀어 골 2개 | `results.dodgeball` `ballResolvedByPhysics` `newSportInvented` |
| 4 끝나지 않는 쉬는 시간 (복도) | 무한 복도에서 시계가 엉터리인 문 6개를 열어 오전의 기억(내가 한 행동) 보고 카드 모으기 → 방송 테이프 단서 → 시간표 복원판에 순서대로 (틀리면 복도 처음으로) | `results.hallway` `timeRestored` `foundBroadcastLog` · 자료 담당·AI 설명서면 힌트 추가 |
| 최종 AI 학교생활 도우미 (교실·급식실 앞·방송실) | 컴퓨터 3대에서 기록(모둠 포스터·급식·소원 설문) 모으기 → 방송실 제어 패널에서 소원 ↔ 진짜 바람 짝짓기 → 엔딩: 빨간 초기화 버튼 두 번(A) / 개선 기준 세 가지를 바르게 적용(B) / B + 숨은 미션 5개(친구 돕기·나눠 먹기·방송 테이프)(C) | `results.ending` `aiCorrected` · 엔딩 뒤 이야기에 앞 사건 결과(축제·새 종목·로봇 모드 등)가 학교 변화로 남음 |

진행 막힘 방지: 교시마다 시간 제한이 지나면 선생님·친구가 정리해 주고 다음으로 넘어가요. 메뉴의 「자리로 돌아가기」「필요한 물건 다시 챙기기」로 길을 잃거나 물건을 떨어뜨려도 복구돼요.
저장: 교시·사건이 시작될 때마다 자동 저장(localStorage). 새로고침하면 「이어하기」로 그 교시(사건) 처음부터. 오래 막히면 선생님·친구가 도와 마무리해요(기록에 남음). 메뉴에서 JSON 내보내기 → 다른 컴퓨터 타이틀에서 불러오기.
